With Vantik Actions you make a workflow that does your work automatically. This
page gives the concepts that you must know before you use Vantik Actions.

## Trigger

A trigger is an event from an integration, for example Discord, GitHub, or
email. A trigger can also be an event in Vantik, for example a comment on an
issue, or a change to the assignee or the labels of an issue. You configure the
triggers in the `triggers` field of a `config.json` file.

This is an example of the configuration:

```json
"triggers": [
  {
    "type": "on_create",
    "entities": [ "Issue" ]
  },
  {
    "type": "source_webhook",
    "entities": [ "discord" ]
  }
],
```

In this example, two events start the action:

- A person creates an issue in Vantik.
- The action receives a webhook event from Discord.

This configuration is flexible. You therefore control when your action runs,
for an internal event in Vantik and for an external event from a platform that
you connect.

## Entity

An entity is usually an integration, or a model in Vantik. For a Vantik model,
an entity is `Issue` or `IssueComment`. For the `source_webhook` type, an entity
is an integration, such as `discord` or `github`.


## Integrations

An integration gives Vantik Actions its power. Your action receives an event
from an external tool, such as Discord or GitHub. Your action also makes an API
call to that tool.

To use an integration, you must ask for access to it. Vantik reads the
integrations of an action and gives it the necessary tokens. Your action then
talks to those external services.

You give the integrations in the `integrations` field of the `config.json` file:

```json
"integrations": ["discord", "github"]
```

This example asks for access to `discord` and to `github`.

## The run function

Vantik calls this function with the details of the event. In the function you
write your own workflow for that event.

```TypeScript
export async function run(eventPayload: ActionEventPayload) {
  switch (eventPayload.event) {
    case ActionTypesEnum.ON_CREATE:
      return onCreateHandler(eventPayload);

    default:
      return {
        message: `The event payload type "${eventPayload.event}" is not recognized`,
      };
  }
}
```

In this example, the run function receives an `on_create` event from a Vantik
entity.
