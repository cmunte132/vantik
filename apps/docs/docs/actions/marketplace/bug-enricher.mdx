## Overview

A person creates an issue in Vantik and puts the `bug` label on it. This action
then does two steps:

1. It sends the details of the issue to the AI model that you configure, and it
   asks that model for a possible solution.
2. It adds the possible solution as a comment on the issue.


:::tip
The full code of this action is
[in the repository](https://github.com/vantikhq/vantik/tree/main/actions/bug-enricher).
:::
