## Overview

Send an email to the address of your team. This action then makes a triage
issue, and it puts all the details of the email thread in the description.

To find the address of your team, open Settings -> Actions -> Email -> Config.

:::tip
The full code of this action is
[in the repository](https://github.com/vantikhq/vantik/tree/main/actions/email).
:::
