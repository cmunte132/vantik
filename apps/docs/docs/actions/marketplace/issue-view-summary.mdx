## Overview

Enable this action, and it gives you a summary of the issues in a custom view.
You select how frequently it does this.

When you configure the action, you can also give the prompt that it uses to
write each summary.

:::tip
The full code of this action is
[in the repository](https://github.com/vantikhq/vantik/tree/main/actions/issue-view-summary).
:::
