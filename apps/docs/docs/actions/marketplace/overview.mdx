This section shows the use cases that the maintainers built. Each one is ready,
and you deploy it and use it in Vantik. The goal is one tool for all your
issues. If you have an idea for a new action, create an issue on GitHub. The
maintainers read every suggestion.

## General actions

A change inside Vantik starts each of these actions.

- **[Bug Enricher](/docs/actions/marketplace/bug-enricher)** - Adds a possible
  solution as a comment on each issue with the `bug` label. It uses the AI model
  that you configure.
- **[Issue View Summary](/docs/actions/marketplace/issue-view-summary)** - Gives
  a summary of the important changes to the issues in a custom view. You select
  how frequently it does this.

## Actions with an integration

These actions get data from a third-party tool, such as GitHub, and they
authenticate with it.

- **[Email](/docs/actions/marketplace/email-actions)** - Makes an issue in
  Vantik triage from an email.
