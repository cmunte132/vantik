title: 'How to write an action: Introduction'
sidebar_label: "Introduction"
---

An action is a core part of Vantik. With an action you write a workflow, and
that workflow then does your work automatically.

:::note
Vantik uses [Trigger](https://trigger.dev) to manage and to deploy the actions
that you write.
:::

Before you read the details on this page, read the
[fundamentals of actions](/docs/actions/core-concepts). That page tells you what
an action is and how an action works.
