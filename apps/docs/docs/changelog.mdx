Vantik uses calendar versions, `YYYY.M.N`. `N` counts the releases in the
month, from 0. Each version below lists the commits that the release added.
The release script writes this page when it makes a release. The tags are on
[GitHub](https://github.com/cmunte132/vantik/tags).
