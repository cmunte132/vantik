## Overview

A view is a dashboard that you configure. It shows your issues from one point of
view. Apply a filter, and the view then shows only the issues that you need.

![](/img/docs/views.png)


## The benefits

- **See only what is important.** A filter makes a custom view, and that view
  shows exactly the issues that you want.
- **Save time, and work with your team.** Save a view that you like, and open
  it again quickly. You can also share it with your team. Every person then
  reads the same list. For example, one view can show only the reports of a
  fault.
- **Read the view again, and analyse it.** A view that you save is easy to open
  again. You therefore analyse the same set of issues over a long period, and
  you see the progress.
