## Overview

The GitHub integration keeps your development process in step with Vantik:

- **Link a pull request.** Link a pull request to the related Vantik issue.
  When a person closes the pull request, the linked Vantik issue moves to
  "Done".
- **Open the issue on GitHub too.** A new issue in a team paired with a
  repository is opened in that repository, and the two are linked.
- **Keep both sides in step.** A change to a linked issue goes out to GitHub,
  and a comment on either side appears on the other.

## How to configure the integration

### Connect GitHub

1. Open **Settings → Integrations → GitHub**.
2. Give Vantik access to your GitHub account.
3. Select the GitHub organisation for the connection.
4. Select all the repositories, or select the repositories that you want.

### Pair teams with repositories

1. On the same page, under **Team mappings**, pick a repository and a team,
   then click **Pair**.
2. A new issue in that team is now opened in that repository as well.

Notes:

- You can pair or unpair only a team you are in.
- Reconnecting GitHub, for example to give it another repository, keeps the
  pairs.
