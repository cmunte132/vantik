An integration gives Vantik much of its power. It connects Vantik to another
tool. Vantik then does a task for you automatically, and it adds more detail to
an issue. The development of an integration is simple. Each integration holds
the authentication details, and those details make a safe connection between
Vantik and the app that you select.

The maintainers want Vantik to be your only tool for project management. To
suggest a new integration, create an issue on GitHub. The maintainers read every
suggestion.
