Vantik is an issue tracker for developers, and the open-source community builds
it. It is simple, it is small, and you can change it.


- **[How to start](/docs/quickstart)** - Learn how to use Vantik


  - **[User guide](/docs/fundamentals/issues)** - Read about the features of Vantik and how to use them


  - **[Actions](/docs/actions/overview)** - Add a third-party application to your workflows


  - **[Self-host](/docs/oss/self-deployment)** - Run Vantik on your own cloud


### How to contribute

Every contribution is welcome, small or large. If you do not know where to
start, open an issue on GitHub.
