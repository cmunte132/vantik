---
title: "How to contribute"
description: "There are many ways to contribute to Vantik."
---

Go to the [GitHub repository](https://github.com/vantikhq/vantik) and open an
issue or a pull request. The maintainers always want more contributors, because
a contributor makes Vantik better. There are many ways to contribute:

- Report a fault.
- Suggest a new feature.
- Write documentation.
- Write code.
- Review code.
- Translate the app.
- Tell other people about the app.
- Give your opinion.
